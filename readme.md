# 👨‍💼 Operation Employee Dashboard

A modern Employee Management Dashboard built using **HTML, CSS, and JavaScript** with REST API integration.

This project helps manage employees with features like search, filter, add, edit, delete, and duplicate records.

---
## 🚀 Features

### 🔍 Search Employees
- Real-time search with debounce
- Minimum 3 character validation
- Employee ID suggestion dropdown
- API-based search
- Cached search results for performance

---

### 👥 Employee Management

#### ➕ Add Employee
- Add new employee records
- Form validation
- Hierarchy validation (designation rules)
- Password support

#### ✏️ Edit Employee
- Update employee details
- Dynamic form modal
- Status update (Active / Deactive)

#### 📄 Duplicate Employee
- Copy existing employee data
- Auto clears Employee ID & Password

#### 🗑 Delete Employee
- Confirmation popup
- Secure API delete request

---

### 🔎 Filters
Filter employees by:
- State
- Zone
- Branch Name
- Super Name

Dynamic dropdown values based on current dataset.

---

### 🎨 UI Features
- Dark / Light theme toggle 🌙☀️
- Responsive design (mobile friendly)
- Glassmorphism UI
- Toast notifications
- Floating Action Button (FAB)
- Animated modals
- Status indicators (Active / Deactive)
